调整算法的理解：
```
                    当前任务 Tc
                         │
                         ▼
                切出 Wcut 给 Tc
                         │
                         ▼
              原任务 To 是否满足？
                    /          \
                  是            否
                  │              │
                成功             ▼
                         寻找空闲替代窗口
                              /       \
                            成功        失败
                            │            │
                          成功           ▼
                                递归重新规划 To
                                      │
                            ┌─────────┴─────────┐
                            │                   │
                          成功                  失败
                            │                   │
                          成功          比较 Pc 与 Po
                                                │
                                     ┌──────────┴──────────┐
                                     │                     │
                                  Pc < Po              Pc > Po
                                     │                     │
                                  需求调整              调整 To
                                                           
```


，一个思想叫做。因此，需要有一个机制，比如给任务添加一个字段，这个标记为1后，这个任务可以随便调整，但是若调整后会出现系统无法满足该任务的需求的情况时，那么这个调整将被拒绝。
