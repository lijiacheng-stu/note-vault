# 对地观测卫星「精确需求」完整描述维度（除时间、地点外全部硬性量化指标）
结合你文档里的建模体系与行业标准，精准需求是**全部参数给定明确阈值、无浮动空间**，缺一不可，分6大类：

## 一、成像质量类（核心硬性精度指标）
1. **空间分辨率（GSD）**
明确要求≤X米，如0.5m、2m、10m；模糊需求只写“高精度/中等精度”，精确需求必须卡死数值。
2. **光谱/载荷类型**
指定必须用：全色、多光谱、高光谱、SAR雷达；指定波段范围、极化方式（HH/VV等），不能替换载荷。
3. **辐射精度/量化位数**
如12bit、辐射误差≤0.3%，定量反演任务必写死。
4. **立体观测要求**
是否必须三线阵立体成像、高程精度阈值（高程误差≤6m）。

## 二、覆盖与幅宽类约束
1. **完整覆盖率**
区域必须100%无缝覆盖，不允许漏拍；模糊需求只要求“大致覆盖”，精确需求是全覆盖硬指标。
2. **单景幅宽要求**
单次成像幅宽≥X km，限定最小拍摄条带宽度。
3. **重访次数**
规划周期内必须观测N次（如3天内拍2次），次数固定不可少。
4. **侧摆角度**
允许/禁止侧摆、最大侧摆角限制，侧摆直接影响分辨率与能耗，精确需求固定角度区间。

## 三、环境与成像条件（硬性否决条件）
1. **最大云量阈值**
云层覆盖率≤5%/10%，超过直接判定任务无效；精确需求给固定百分比，模糊只要求“少云”。
2. **光照/太阳高度角**
光学卫星强制太阳高度角≥20°，避免阴影过大；雷达无光照约束但可限定入射角。
3. **观测入射角/俯仰角**
SAR任务严格限定雷达入射角区间，保证形变测量精度。
4. **规避约束**
禁止太阳直射载荷、避开南大西洋异常区、避开月掩星等，全部是固定硬边界。

## 四、任务优先级与执行保障
1. **固定优先级等级**
一级应急、二级常规、三级普查，高优先级任务必须优先分配资源，文档指标：高优任务满足率≥95%。
2. **任务执行保障要求**
必须分配2颗卫星冗余观测、不允许单星单点覆盖；突发应急精确需求常带冗余约束。

## 五、卫星平台与资源约束
1. **存储/下传要求**
单任务数据量上限、必须匹配指定地面接收站，成像后X小时内完成数传下传。
2. **能耗约束**
单次成像耗电上限，不允许卫星超出当日电量预算。
3. **姿态机动时间**
两次观测间调姿时长不得超过给定值，否则放弃该窗口。

## 六、数据产品交付硬性要求
1. **产品等级**
必须0级/1级/2级标准化数据产品，固定处理标准。
2. **定位精度**
平面定位误差≤X米、高程误差≤X米，测绘类精确需求必带。
3. **交付时限**
成像完成后几小时内推送数据，固定时效红线。

# 一句话区分精确 vs 模糊需求
- **精确需求**：上面所有参数全部给出**固定数值阈值**，任何一项不达标即任务不满足；
- **模糊需求**：只给范围描述（近期、高精度、少云、大致覆盖），允许指标小幅浮动，用匹配度评估是否合格。

# 完整精确需求示例（直观对照）
> 时间：8月5日 9:00–12:00；地点：某市全域矢量边界
> 分辨率≤0.8m，全色+4波段多光谱，云量≤10%，太阳高度角≥25°，全域100%无缝覆盖，3天内仅需1次观测，优先级一级，成像后2小时内地面站下传，平面定位精度≤10m。
每一条都是硬约束，少一条、指标放宽一点都不算精确需求。
