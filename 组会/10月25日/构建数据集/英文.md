- patch 图像块
- GSD = Ground Sampling Distance 地面采样距离
	- 含义：它表示影像中一个像素对应地面上的多大距离。
-  DSM = Digital Surface Model 数字表面模型
	- 含义：描述地表及地物表面高度的数据。例如，地面、房顶、树冠都有对应的高度值。
- TOP = True Orthophoto 真正射影像
	- 含义：一张经过几何校正的航空俯视照片。它尽可能消除了建筑物倾斜、地形起伏等造成的位置偏差，使影像中的地物位置更准确。
- elevation 高程
	- 含义：相对于指定基准面的垂直位置。
- height 高度
	- 含义：述相对于某个物体或表面的垂直距离。
- nDSM =  normalised DSM
	- 含义：从 DSM 中减去对应位置的地面高程，得到的表示地物表面相对于地面高度的栅格数据。
- Raster Data 栅格数据
	- 含义：就是把一个区域划分成规则的网格，每个网格单元存储一个数值或一组数值的数据形式。
- GT = Ground truth 地面真值
