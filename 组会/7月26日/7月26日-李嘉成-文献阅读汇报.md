## 关于遥感图像语义分割中的编码器-解码器架构的调查/综述/总结
这周又读了一篇关于遥感图像语义分割的文章，我发现，没有值得特别汇报的点，值得汇报的点都被以前汇报的东西覆盖了。我发现，在基于CNN的遥感图像语义分割这个范畴下，尽管每篇论文都有自己的创新点，提出了新的模块、新的结构，但是，当把这些模型放在一起比较之后，会发现它们围绕的核心问题具有很强的共性：比如，如何提取更有效的特征，如何融合不同尺度的特征，如何融合多模态特征，以及如何恢复更加精细的空间细节。此外，我发现，几乎所有的模型都采用了编码器解码器架构， 尽管绘制的图有差异，但是都可以用一个比较通用的范式来解构。因此，这次，我想在基于CNN的遥感图像语义分割大前提下，从编码器-解码器架构的角度，对这些模型进行梳理。
为了引导这次梳理，我先提出了一些比较有价值的引领性问题。

### 1. 问题框架
1. 同样是对图像进行语义分割， 为什么对遥感图像的处理要单独另说？遥感图像，和自然图像相比，存在哪儿些独有的困难？解决困难/问题的方向在哪儿？
2. 编码器解码器架构常常用于遥感图像的语义分割，为什么编码器解码器架构非常适合遥感图像语义分割？
3. 在看过的文章中，有哪儿些网络使用了编码器解码器架构？这些网络中，编码器是如何设计的？解码器是如何设计的？ 
4. 这些基于编码器解码器架构模型的设计有哪儿些槽点，哪儿些值得借鉴的地方？评价这种模型优劣的思考的框架是什么？自己如何趋利避害设计出相对自己的优秀的模型？
### 2. 遥感图像语义分割所面临的困难以及解决方向
1. 类间差异低: 低矮植被和树木可能难以区分。 因此，可能需要引入其他多模态数据，例如，SAR，DSM。
2. 类不平衡：不同类别的对象在图像中的占比是不同的。这导致模型对占比小的类别的预测性能低。因此，可能需要对损失函数进行调整，增加对占比少的类别的损失权重。
3. 类内差异大：（这两张图片都包含被归类为“船只”的物体，这些物体在形状、大小、颜色和位置上存在显著差异。）因此，类内差异使得单一尺度的特征难以完全代表同一类别中的所有实例，需要多尺度特征。![[Pasted image 20260725224051.png]]
4. 在现有的工具上，ResNet，Xception，HRNet等骨干网络包含的下采样操作（步长卷积，池化），能增加感受野，得到语义更丰富的特征，同时也损失了空间细节。而语义分割任务，要求对图像中的每个像素进行准确分类，这不仅需要高层语义信息，还需要精确的空间定位信息。因此，需要恢复空间细节。
编码器-解码器架构中，编码器能够提取多尺度特征；解码器通过逐级上采样，并与编码器不同阶段提取的特征进行融合，实现多尺度特征的融合，获得兼具空间细节与语义信息的融合特征，并用该特征，经过预测头，得到最终预测结果。因此，编码器-解码器架构非常好地解决三四存在的问题，使其得到广泛的应用。
### 3. 编码器解码器架构的结构归纳
#### 3.1 理论归纳
以下是经典编码器解码器的结构：（参照FPN对这个结构的命名）
![[Pasted image 20260725155508.png]]
上面的结构，很简单，仔细观察后，发现存在四个结构：
- 编码器：
	- 自下而上的路径(Bottom-up pathway)： 经过骨干网络的前馈计算，得到多尺度特征，其中浅层特征保留丰富的空间细节，深层特征包含较强的语义信息；
- 解码器
	- 自上而下的路径(Top-down pathway)：通过上采样，让空间上更粗糙，语义上更强的自上而下的特征得到更高的分辨率。使其能够与空间信息更丰富语义信息更弱的自下而上的特征融合。
	- 横向连接(lateral connection)：融合空间分辨率相同的自下而上特征与上采样后的自上而下特征，得到空间信息丰富，语义信息强的融合特征。
	- 预测头：利用兼顾目标边界细节和语义表达能力的融合特征，生成与输入图像尺寸一致的像素级预测结果。

统一下术语：

![[Pasted image 20260725232130.png]]
图的价值：
- 这张图看似非常简单，但是内涵确非常丰富。从设计模型的角度，无论是自下而上的特征提取，自上而下的上采样，横向连接的融合特征，预测头的生成预测结果，都可以采用不同的不同的模块，这样就海量的组合变化进行调试。此外，根据不同应用场景的需求，可以对这一结构进行剪裁，用以权衡准确率与计算效率。
- 从模型分析的角度，可以把任意采用这一架构的模型，都解构成这四个部分，实现模型结构的梳理。基于此，便于模型优化、各模型间进行横向对比。这就形成了一个分析框架。
接下来，用这个简单的图，用这四种结构解构，对我当前看过的所有的采用编码器解码器架构的模型进行模型分析。

#### 3.2 模型分析
我看过的采用这种结构的网络有五个, 单模态有UNet, UperNet, DeepLabv3+，多模态有MGFNet, CEGFNet（这是这周新看的）。下面将从四种结构解构模型和评价/启发两个方面来讲。
##### 3.2.1 U-Net：2015
![[Pasted image 20260725140453.png]]
	- 自下而上：对应特征提取，结果是得到多尺度特征。普通卷积 + 最大池化
	- 自上而下：对应上采样。 转置卷积（上采样卷积）
	- 横向连接：对应多尺度特征融合。 拼接 + 普通卷积 
	- 预测头：对应最终多尺度融合特征处理成最终预测结果。 `1 * 1` 卷积
	- 评价：从现在的眼光看好像没什么特别的，但是当时确非常特别。Unet第一次将横向连接实现多尺度特征融合引入编码器解码器架构，并在医学图像语义分割任务中取得突破性效果。做了开创性的工作。
##### 3.2.2 UperNet: 2018 (特征金字塔是2016)
对FPN的理解，以及区分Unet。FPN设计的初衷是通过得到得到一套具有不同尺度、各个尺度兼顾空间细节和语义信息的特征金字塔，这套特征为下游的目标检测奠定基础。所以，FPN的作用是特征提取，所以它是编码器。


![[Pasted image 20260725141118.png]]
- 自下而上：FPN
- 自上而下和横向连接：被剪裁，直接上采用，统一多尺度特征分辨率，而后拼接。
- 预测头：`3 * 3`卷积 + `1 * 1` 卷积
- 评价/启发：对原编码器解码器架构在自上而下和横向连接上进行了剪裁。因为经过在编码器阶段后，采用FPN使得各尺度特征均兼顾了空间细节和语义信息，因此，这种裁剪具有可行性。用FPN作为编码器，是一种创新，以此为灵感，可以设计出一个嵌套的编码器和解码器结构。
###### 插曲（可跳过）
问题：UNet、FPN、encoder-decoder achitecture都采用“多尺度特征融合”的思想， 三者架构几乎完全相同。FPN为什么能在Unet后发表文章？（UNet、FPN、encoder-decoder achitecture之间的关系）
- FPN，设计的初衷是用于目标检测，目的是一套具有不同尺度、各个尺度兼顾空间细节和语义信息的特征金字塔，这套特征为下游的目标检测奠定基础。
- encoder-decoder achitecture， 是一个抽象范式，在语义分割任务中，其目的是得到一个兼顾空间细节和语义信息的融合特征，这一特征为下游得到像素级的预测结果奠定基础。
- Unet，采用的是encoder-decoder achitecture，它这种架构的是一个实例。
##### 3.2.3 DeepLabv3+ : 2018![[Pasted image 20260725141703.png]]
- 自下而上： ResNet/Xception + 空洞卷积
- 自上而下：双线性插值
- 横向连接：`1 * 1` 卷积 + 拼接
- 预测头： `3 * 3` 卷积 + 双线性插值
- 评价/启发：在编码器侧，用空洞卷积替换带步长的卷积或池化操作等下采样操作，既提取了丰富的语义信息，又保留空间细节，但增加了计算量。在解码器侧，通过减少多尺度特征融合的次数，降低了解码过程中的计算开销，从而一定程度上抵消了编码器采用空洞卷积所带来的额外计算成本。 这个设计是很好的。
##### 3.2.4 MGFNet：2024
![[Pasted image 20260725140111.png]]
- 这是多模态的编码器解码器的模型。
- 自下而上：首先要识别出，哪儿一部分对应经典模型中自下而上的多尺度特征。答案应该单一模态提取的多尺度特征， 而是两模态的多尺度融合特征。因此，这里的编码器的构成应该包括单一模态的编码器 + 多模态的特征的融合模块。光学图像采用的HRNet，SAR图像采用ResNet + MGF模块。
- 自下而上/横向连接：类似于UperNet，这两部分被裁减，直接上采用，统一多尺度特征分辨率，而后拼接，得到一个融合特征。
- 预测头：Conv + BN + Rlu + Conv + 上采样
- 评价/启发：
	- 这个模型的性能肯定是不好的。每个尺度的融合特征，是由两个来自相同的层级不同模态的特征融合得到。这两个特征要么都空间细节丰富，但语义信息弱；要么都空间细节丢失，但语义信息强。它们融合后的特征，尽管交换了互补信息，但是在空间细节和语义信息只兼顾了一个方面。这个时候，要发挥解码器的作用，通过融合多尺度融合特征，得到兼顾空间细节丰富和语义信息强的特征。但是这个模型，直接就拼接了，然后传给预测头了。这是不可以的。UperNet之所以可以，是因为它的多尺度特征是由FPN提取，每个都兼顾空间细节和语义信息。
	- 所以多模态的模型，至少可以包含两类融合模块，一类用于融合多个模态特征；一类用于融合多尺度融合特征。前者位于解码器，后者位于编码器。
	- 多模态特征融合模块，可以有不同的设计哲学，MGFNet是基于门机制的，其他的还可以基于注意力机制。

##### 3.2.5 CEGFNet: 2021
![[Pasted image 20260725141921.png]]

- 自下而上：自下而上的多尺度特征，$X^i_{RD}$ ，它不仅融合了两个模态的特征 ，还融合了前一个阶段的融合特征，这是一个创新点。 但前一个阶段的融合特征空间细节多，语义信息少，因此，它的加入，更能会使得更高级的语义信息的提取更加困难。因此，需要做一个消融实验，看一下前一个阶段的融合特征进行融合的必要性。文章没有做。$X^i_{Rout}$ ，它竟然不是通道门，而$X^i_{R}$ 一样形状，有0～1的数构成的张量。这个计算量是应该省的。
- 自上而下： 双线性插值。自上而下多尺度融合特征，M。
- 横向连接：GCM，参考的 DeepLabv3+，对一个特征用多个感受野的空洞卷积在分别提取特征，再融合的做法。MAD也是复杂的，使用了自注意力，对Gi进行了进步一优化，最后上一阶段的M进行融合。
- 预测头：PTM，预测终端模块。
