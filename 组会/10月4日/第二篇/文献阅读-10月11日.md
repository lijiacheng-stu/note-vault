## 1. 网络架构的介绍
![[Pasted image 20261010202435.png]]
**整体：**
- 使用经典的encoder-decoder架构，在编码器部分使用4个stage，用于提取多尺度特征。解码器通过DBMFA module，融合多尺度特征并逐步恢复空间分辨率，最终生成像素级语义分割结果。

**encoder**：由4个阶段构成，每个阶段由一下以下结构组成
- Conv token embedding：跟ViT，PVT中，Patch embedding layer相同。是一个卷积层，stride = kernel size= 4， 2， 2， 2，使得图像或特征图的空间分辨率逐渐下降，通道维度逐渐上升。
- Dual attention Transformer Block：原文是这么介绍的**提取包含全局、局部、上下文、位置和通道信息的丰富复合特征，帮助模型理解每个像素的语义信息，提高分割的鲁棒性。**

**decoder**
- **DBMFA module：** 4MLP  + BiFPN（dynamic sampling），融合多尺度特征
- semantic segmentation：是一个预测头，跟传统的预测头没有区别，对多尺度融合特征进行逐点卷积生成类别预测图，经上采样恢复至原图分辨率，并通过 Softmax 输出像素级类别概率。

### 1.1 DBMFA module

![[Pasted image 20261010220641.png]]
过程：
- 通过MLP，将E2，E3，E4的通道维
- 度统一为C
- 通动态上采样，下采样，权重策略，得到多尺度特征P2，P3，P4，每个特征都融合了不同尺度的信息。
	- 先计算P1，P1融合了E3和E4
	- 再计算P2，P2由P1和E2‘得到，因此，P2融合了E2，E3，E4的信息。
	- 最后同理求，P3，P4
![[Pasted image 20261010222358.png]]
DBMFA = Dynamic bidirectional multiscale feature aggregation
- multiscale feature aggregation: 表明模块的功能是多尺度特征融合
- Dynamic：表示特征融合融合过程中，涉及的上采样方式，存在dynamic upsampling
- bidirectional： 强调特征融合的过程是双向的，因为与经典的UNet，DepLabv3+，或者SegFormer采用自上而下逐渐恢复分辨率并融合特征的单向路径不同，上面的特征的融合过程是双向的。
#### 1.1.1 Dynamic upsampling
1. 操作Grid Sampling:
	- X: 它是特征图，shape是(C, H1, W1)
	- S: 它是采样集合，shape是(2, H2, W2)，第一个维度表示x，y的坐标
	- X' = grid_sample(X, S)：依据采样集合S提供的坐标，对特征X执行双线性插值采样，得到输出特征X‘。 （S就是X‘在X中采样位置的集合。）
2.  如何得到采样集合S呢？
	- 设上采样率为s，X的形状为(C, H, W)
	- 得到偏移量：O = Linear(X) ，O.shape = (2$s^2$, H, W), 然后Pixel Shuffling作，得到 (2, sH, sW）
	- S = G + O，其中G表示原始采样网格
3. 如何得到原始采样网格呢？
	- ![[Pasted image 20261010232109.png]]
	- 每个像素都是一个边长为1的像素块，最左上角像素的中心点坐标为(0, 0)，继而可以得到其他位置坐标。
	- 当上采样率为2时，一个原图的像素块，将会对应4个上采样后的像素块，采样位置是有两种方案。如上，方案一，采样位置为原像素块中心点的坐标。方案二，把4个像素块缩小，放到原像素中，每个像素块的中心点的坐标为采样位置。
4. 还能如何优化呢？
	- 优化1: 上面的方法，所有通道共用一套采样集合。可以将沿通道维度分成g组，每组共用一套
	- 优化2: 确定初始采样网格后，由于偏移范围比较大，局部的s2采样位置的采样范围会严重重叠，这将导致预测伪影。解决办法是：

### 1.2 Dual Attention Transformer Module
功能：提取包含全局、局部、上下文、位置和通道信息的丰富复合特征，帮助模型理解每个像素的语义信息，提高分割的鲁棒性。
![[Pasted image 20261010234715.png]]
- 经典的编码层中，MHA模块替换成两个分支，分别是Global branch和Local branch
	- Global branch：有CWSA，以提取全局特征
	- Local branch：有CCAB，有Cov和ECA构成。其中，Conv，以提取局部特征；ECA，通过对局部通道信息建模，对局部特征进行增强。
	- 通过逐元素加进行两类特征的融合

#### 1.2.1 ECA
![[Pasted image 20261010235631.png]]
- 沿着空间维度，作全局平均池化，得到聚合特征
- 聚合特征，通过1D卷积，得到通道的权重
	- 1d卷积的卷积核的大小随C的大小，自适应调整，非线性，正相关。
	- 一个通道的权重的值仅于该通道相邻的几个通道有关，因此，ECA实现的是局部夸通道交互
- 通道的权重 与 原特征相乘，得到通道增强特征

### 3. 文章总结
- 为了解决地理空间目标密集分布，遮挡，类间差异小等问题，采用了dual attention transformer encoder，里面的CWSA提取全局特征，CCAB提取局部特征，从而得到了包含全局、局部、上下文、位置和通道信息的丰富复合特征
- 用dynamic upsample替代原BiFPN中的双线性插值，促进了多尺度特征的融合

### 4. 经验总结
- 微创新或零创新：模块的设计和整体网络架构没有创新。
	- 文章提出了三个模块，CCAB，CWSA，DBMFA Module，本质上都是已有技术的组合，没有提出原创性的新的技术。
	- 网络沿用经典的编码器-解码器范式，未对整体架构或特征处理流程进行实质性创新。仍然是编码器负责提取多尺度特征，解码器负责融合多尺度特征并逐步恢复空间分辨率，最终生成像素级语义分割结果。
- 用dynamic upsample替代双线性插值作为创新点值得借鉴。
- 文章通过在他人原创的技术的前后增删MLP或Cov，从而用CCAB替换ECA，用CWSA替换CSwin，用DBMFA替换BiFPN的处理方式，也是值得借鉴的，这样显得文章算法设计，而不是工程实现，是个人原创整合，而不是抄袭。
- 缝合时，要选择多种技术，并且要选择轻量级的技术。
