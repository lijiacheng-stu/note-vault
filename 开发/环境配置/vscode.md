## command palette
1. 打开 **Command Palette** （命令面板 ，/ˈpælət/）：
	- 快捷键`command + shift + p`
	- or "**View** > **Command Palette**"
	- or 在标签页中，右键，最下面有Command palette
2. 三种mode：
	- **Command mode (`>`)**
	- **Quick Open mode**
	- **Symbol search mode (`#`)**
3. 常用的命令：
	- Preferences: Open User Settings(Json)
## 区分一些补全方法概念
- inline suggestion
	- 由
- code completion
	- 类名补全
	- import 补全
	- 成员补全
	- 对象方法参数补全
- postfix completion
	-  `ingredients.for`
	- `name.null`
- live template / snippet
	- `sysout`
	- `psvm`
	- `fori`
- intelliSense ：
	- code completion
	- go to definition
	- Parameter Info
	- Hover Information
