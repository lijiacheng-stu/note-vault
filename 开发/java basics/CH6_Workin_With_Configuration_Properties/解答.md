问题1: 这提到的autoconfigured components有哪儿些呢？他们的作用分别是什么呢？
答案：
- 数据库相关：
	- data source
	-  specify the database initialization scripts
- 嵌入服务器：
	- set the servlet container’s port
	- set it up to handle HTTPS requests
- logging：
	- change the logging levels and perhaps to specify a file where the logs should be written.
	- logback.xml （可以平替）
