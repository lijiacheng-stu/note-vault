@autowired相关：
- 一个类只有一个构造器时，Spring 会自动用它来注入，不需要任何注解。
- @Bean 方法的参数自动注入

lambda表达式：
- 函数式接口。一个接口，里面定义了一个函数。现在需要一个函数式接口对象，即，一个对象重写了函数式接口中的函数。
- () ->  能返回这样的对象。 
这个对象得到的是函数体是有了，但是函数的形参没有定义，那个函数体中调用的时候给形参赋值。


```
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http){
        return http
            .authorizeHttpRequests((authorize) -> 
                authorize
                    .requestMatchers("/design", "/orders").hasRole("USER")
                    .requestMatchers("/", "/**").permitAll()
            )
            .formLogin((formLogin) -> 
                formLogin
                    .loginPage("/login")
            )
            .build();
    }
```
- 一个对象http，调用了三个函数authorizeHttpRequests、formLogin、build
- authorizeHttpRequests、formLogin的形参是函数式接口对象，因此我们需要传递函数式接口对象给这两个函数，上面通过lambda表达式生成这样的对象，关键操作是override抽象函数。
- 被重写的抽象函数本身有特定类型的形参。抽象函数在authorizeHttpRequests、formLogin被调用，调用时给形参赋值。这个形参的操作是步骤二中定义的。

思考：这种写法的使用场景时什么呢？
- 传给抽象函数的参数，是配置项。通过上述方法可以修改默认的配置项。
- 传给抽象函数的参数，是参数，我们通过参数可以定义自己的操作。
