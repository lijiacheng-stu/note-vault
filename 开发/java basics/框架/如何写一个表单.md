核心的内容：
- `<label>`和`<input>`的联动机制
- 提交表单
- 表单提交的method + URL如何定义


- `<form>`
	- method
	- action

- `<label>` 是文本标签，作用是把一段说明文字和一个表单控件绑定在一起。
	- for="phone" 是它的关联手段：for 的值必须等于某个表单控件的 id。绑定后，点击「Phone:」这几个字，浏览器会自动把焦点放到对应的输入框上（对无障碍/屏幕阅读器也友好）。
- `<input>`
	- type = "text"， 输入文本框
	- name = "phone", 提交时作为 phone=xxx的键（后端绑定）
	- id = "phone"，点击label的说明文字「Phone:」会聚焦到输入框

	- type=“submit”, 提交按钮, 点击它会把整个 `<form>` 的数据提交出去（提交到 th:action 指定的 /register，用 method 指定的 POST）。
	- value="register"
